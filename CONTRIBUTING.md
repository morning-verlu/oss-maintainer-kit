# Contributing

Thanks for helping improve `oss-maintainer-kit`.

## Development

```bash
npm install
npm run check
```

## Pull Requests

Keep pull requests focused. A good PR includes:

- the problem being solved
- the behavior change
- tests for changed logic
- any new maintainer workflow documentation

## Maintainer Review Policy

Maintainers should review:

- security-sensitive code paths
- changes that call external services
- changes that affect generated labels, priorities, or contributor replies
- changes that alter GitHub Action behavior

Automated review output is advisory. Final decisions stay with human maintainers.
