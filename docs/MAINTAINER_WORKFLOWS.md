# Maintainer Workflows

## Issue Triage

Input: issue title and body.

Output:

- category
- priority
- suggested labels
- reproduction status
- maintainer next steps
- contributor reply draft

## Pull Request Review

Input: pull request diff.

Output:

- bug and regression risks
- security-sensitive patterns
- missing tests
- changed public API surface
- manual verification checklist

## Release Notes

Input: commits, pull request titles, or changelog fragments.

Output:

- Added
- Changed
- Fixed
- Security
- Maintenance

The generated notes are drafts. Maintainers should edit them before release.
