# Governance

`oss-maintainer-kit` is currently maintained by its founding maintainer.

## Maintainer Responsibilities

- review pull requests
- triage issues
- publish releases
- respond to security reports
- keep automation transparent and auditable

## Adding Maintainers

Contributors may become maintainers after sustained, high-quality contributions and agreement with the project's review and security practices.

## Decision Making

The maintainer prioritizes changes that improve practical open-source maintenance workflows, reduce false confidence, and keep the project easy to run in CI.
